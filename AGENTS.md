# Agents

- Treat this repository as the Swift package for Numerics Extended.
- Read and follow [Contributing](/CONTRIBUTING.md) in full for all repository work, including issues, milestones,
  branches, source code, tests, documentation, commits, pull requests, releases, and tags.
- Read and follow [Coding Style](/Docs/CodingStyle.md) in full when changing source code, tests, documentation,
  or configuration files.
- When working in the Codex desktop app, open the review panel on the right at the start of repository work and after
  making changes. Use `open_in_codex` with a review target and `placement: "right"` when available. Show the unstaged
  diff for working changes or the staged diff when the relevant changes have been staged.
- Leave all changes you make unstaged unless explicitly asked to stage them. Preserve any changes the developer has 
  already staged.
- Leave newly created files untracked unless explicitly asked to add them to Git. Do not automatically run `git add`
  or equivalent tracking or staging actions in an app.
- Do not create commits unless explicitly asked to do so.
- Do not push commits unless explicitly asked to do so. Permission to commit does not imply permission to push.
